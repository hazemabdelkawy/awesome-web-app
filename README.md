# awesome-web-app

A modern web application built with Node.js and React.

## Getting Started

```bash
npm install
npm run dev
```

## Claude Code Integration

This project is configured to use Claude Code for AI-assisted development.
The team uses the `dev-assistant` plugin for session analytics and productivity tracking.

### Setup

1. Install Claude Code: `npm install -g @anthropic-ai/claude-code`
2. Open the project: `cd awesome-web-app && claude`
3. The `dev-assistant` plugin will be automatically configured via `.claude/settings.json`

## Project Structure

```
src/

  auth.js        - Authentication module
  api.js         - API handlers
tests/
  auth.test.js   - Auth unit tests
```
